# Archive — rien ici ne fait foi

Ces documents décrivent le projet tel qu'il était au moment où ils ont été écrits. **Aucun n'est
rafraîchi, et c'est délibéré** : les réécrire effacerait la trace de ce qui a réellement été décidé
et mesuré à ce moment-là, ce qui est exactement leur seule valeur restante.

Pour l'état courant, lire [`../architecture/`](../architecture/). Pour les raisons, lire
[`../carnets/`](../carnets/).

---

## Ce qu'ils contiennent, et ce qui est faux dedans

**`CURRENT_STATE.md`** — un audit du code, en lecture seule, daté d'avant les chantiers brouillard,
grande carte, décor et expéditions. Il relève `ReserveCap = 25000f` (le code livre **70 000**) et une
arborescence sans découverte, sans secteurs, sans missions ni décor. Il était présenté par le README
du dossier Intro comme l'une des deux sources faisant foi pour l'implémentation ; il ne l'est plus.

**`ALIGNEMENT_PROJET.md`** — le relevé des écarts entre le projet et le GDD au moment du remaniement
de l'introduction, avec pour chaque valeur son état d'alors et sa cible. Ses colonnes « valeur
actuelle » décrivent un dépôt qui a changé depuis, et au moins une de ses cibles a bougé : il vise un
`ReserveCap` de 60 000, le code en livre 70 000.

**`TASK_01` à `TASK_05`** — cinq tâches, toutes réalisées, chacune avec son commit. Leur contenu
n'est pas faux : il décrit l'état au moment de la tâche. Ce qui l'était, c'est le parcours de lecture
que le README du dossier Intro en faisait, et qui menait un lecteur à appliquer aujourd'hui un
plafond de 60 000 et un rayon de 22.

**`README_Intro_original.md`** — le README du dossier Intro avant le rangement, conservé parce qu'il
est ce qui donnait leur autorité aux documents ci-dessus.
